# Aura Health Sanctuary & Executive Medical Lounge

A high-converting, luxury client acquisition website template designed specifically for multi-specialty medical care centers covering **Cardiology, Dental, Gynecology, Diagnostic Labs, Physiotherapy, and Family Medicine**.

## Key Features
- **Nordic Serene Aesthetics**: Warm alabaster surfaces, deep sage greens, champagne gold accents, and subtle glassmorphic elements.
- **Multi-Specialty Symptom & Triage Navigator**: Intelligently routes patients from symptoms to the correct clinic specialty.
- **Executive Checkup & Lab Estimator**: Interactive calculator with 0% EMI financing projections and pre-filled WhatsApp link.
- **Embedded 432Hz Sanctuary Audio Player**: Real-time Web Audio API ambient sound player to alleviate clinical visit anxiety.
- **Frictionless Booking & Digital Intake**: Dynamic date/slot scheduler + paperless HIPAA-style registration + instant WhatsApp handover.
- **Omnipresent VIP Concierge**: Reactive floating bubble with one-tap emergency call and direct clinical desk messaging.

## Getting Started Locally

```bash
# Install dependencies
npm install

# Run dev server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to view the application.

## Deploying to GitHub & Vercel

### Option 1: Direct GitHub Push
```bash
git init
git add .
git commit -m "Initial commit - Aura Health Sanctuary Template"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/aura-health-sanctuary.git
git push -u origin main
```

### Option 2: 1-Click Vercel Deployment
1. Push this directory to your GitHub account.
2. In the Vercel Dashboard, click **Add New > Project** and import the repository.
3. Vercel will automatically detect Next.js and build with zero extra configuration.
